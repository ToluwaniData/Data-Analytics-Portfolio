# Global Debt Analysis  
*By Toluwani Emmanuel*  

## Objective  
This project analyzes global debt trends from 1950 to 2022 using the **Global Debt Database (GDD)** from the International Monetary Fund (IMF). The dashboard explores debt records across 190 countries, covering advanced economies, emerging markets, and low‑income countries. It highlights different types of debt including government, corporate, household, and private debt.  

## Tools Used  
- **Power BI** (dashboard design and visualization)  
- **Power Query** (data cleaning and transformation)  
- **DAX** (custom measures and calculations)  

## Data Preparation  
- Dataset sourced from the **IMF Global Debt Database (1950–2022)**.  
- Built a unified data model with measures for government, corporate, household, and private debt.  
- Added interactive slicers for **Year**, **Country**, and **Indicator**.  
- Card visuals display key KPIs for quick insights.  

## KPIs Displayed  
- Global Average Debt %: 51.63  
- Median Debt %: 38.21  
- Max Debt %: 677.18  
- Total Indicators: 5  
- Total Countries: 189  

## Key Insights  

1. **Average Debt % by Indicator (Bar Chart)**  
   - Non‑financial corporate debt: highest global average (67.43%).  
   - Household debt: lowest global average (37.30%).  
   - Insight: Corporations contribute more to global debt compared to households.  

2. **Global Average Debt % by Indicator (Pie Chart)**  
   - Non‑financial corporate debt: 25.96%  
   - Private debt: 21.02%  
   - General government debt: 20.23%  
   - Central government debt: 18.44%  
   - Household debt: 14.36%  
   - Insight: Debt is distributed across sectors, with corporate and private debt dominating.  

3. **Global Debt Trend (1950–2022) (Line Chart)**  
   - Peak: 2020 (70.62%).  
   - Lowest: 1963 (26.48%).  
   - Insight: Global crises, such as COVID‑19, drive debt levels upward.  

4. **Global Average Debt % by Indicator (2022) (Bar Chart)**  
   - Private debt highest (82.62%).  
   - Household debt lowest (44.98%).  
   - Insight: Recent debt growth driven more by private sector borrowing.  

5. **Top 5 Countries by Average Debt % (Bar Chart)**  
   - Cyprus (141.05%)  
   - Hong Kong SAR (123.82%)  
   - Netherlands (112.12%)  
   - Eritrea (110.91%)  
   - Nauru (108.46%)  
   - Insight: Debt challenges are concentrated in specific economies, far above global averages.  

6. **Debt Trend by Indicator (1950–2022) (Line Chart)**  
   - Household debt peaked in 2022 (44.98%), lowest in 1964 (20.65%).  
   - Central government debt peaked in 2020 (67.01%), lowest in 1974 (20.05%).  
   - General government debt peaked in 2020 (68.55%), lowest in 1973 (28.09%).  
   - Non‑financial corporate debt peaked in 1993 (79.56%), lowest in 1950 (26.05%).  
   - Private debt peaked in 2020 (86.63%), lowest in 1950 (26.02%).  
   - Insight: Private and government debt surged during crises, while household debt remained relatively stable.  

## Outcome  
This dashboard provides a comprehensive view of global debt trends across countries, indicators, and decades. It reveals how debt has evolved, surged during crises, and concentrated in specific economies. The analysis demonstrates how data can be transformed into actionable insights for policymakers, researchers, and analysts.
